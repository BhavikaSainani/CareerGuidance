# CareerGuidance
Career Guidance Project
📌 Overview

The Career Guidance Project is a personalized career recommendation platform designed to help students make informed academic and professional decisions. The system evaluates student interests and skills through a structured general knowledge test and provides tailored career guidance based on the results.

🎯 Objectives

Assess students’ interests and aptitude using a general knowledge test

Provide personalized career recommendations

Support students in making informed academic and professional choices

Reduce confusion in career selection through data-driven guidance

🛠️ Key Features

General knowledge–based assessment test

Interest and skill evaluation

Personalized career recommendations

User-friendly and interactive interface

Scalable design for future enhancements

🧠 How It Works

User registers/logs in to the platform

User completes a general knowledge test

System analyzes responses to assess interests and skills

Personalized career guidance is generated and displayed

🧩 Technology Stack

Programming Language: Python

GUI Framework: Tkinter

Database: MySQL

Database Connector: mysql-connector-python

🚀 Future Enhancements

Integration of aptitude and personality tests

AI-based career prediction

Career roadmap and learning recommendations

Admin dashboard for analytics

📂 Project Status

Completed as an academic project and open for further improvements and feature expansion.
